# Day 19 - Exploratory Testing Charter

## 1. Test Objective

Explore shopping cart and checkout-related features to identify unexpected behavior in price calculations, coupon validation, and gift card validation.

## 2. Test Website

AcademyBugs.com

## 3. Test Environment

- Operating System: Windows 11
- Browser: Google Chrome
- Testing Method: Exploratory Testing

## 4. Time-box

- Planned Duration: 90 minutes
- Actual Duration: Approximately 45 minutes
- Main Time Spent: Investigating unexpected behavior, retesting, and capturing screenshots.
- Note: The actual session was shorter than the planned time-box.

## 5. Test Scope

- Shopping cart quantity and price calculations
- Coupon validation
- Gift card validation
- Checkout page observations

## 6. Key Risks

- Incorrect cart total calculations
- Unexpected coupon validation behavior
- Unexpected gift card validation behavior
- Inconsistent checkout information

## 7. Out of Scope

- Real payment transactions
- Order fulfillment
- Performance testing
- Security testing

## 8. Testing Approach

- Explore features based on identified risks.
- Observe system behavior.
- Record unexpected results.
- Retest suspicious behavior.
- Distinguish confirmed defects from unverified observations.
