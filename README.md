# saas-qa-portfolio

Manual QA testing portfolio with test scenarios, bug reports, and testing notes.

## Repository Structure

- `bug-reports/` - Bug reports with reproduction steps, expected results, actual results, severity, priority, and evidence.
- `test-scenarios/` - Functional, negative, and boundary test scenarios.
- `notes/` - QA concepts and daily learning notes.

## Current Focus

- Manual functional and exploratory testing
- Equivalence partitioning and boundary value analysis
- Severity and priority assessment
- Writing clear and reproducible bug reports in English
